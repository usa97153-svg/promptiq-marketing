# PromptIQ — 50 AI-промптов для маркетинга и контента

Интерактивное веб-приложение с каталогом из 50 профессиональных инженерных AI-промптов по формуле: **Роль + Задача + Контекст + Формат + Ограничения**.

## 🚀 Быстрый запуск

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск в режиме разработки
```bash
npm run dev
```
Приложение откроется по адресу `http://localhost:3000`.

### 3. Сборка и запуск для Production
```bash
npm run build
npm start
```

---

## 🔑 Доступ и пароли

При первом открытии сайт запрашивает пароль:
- `promptiq2025`
- `piq-marketing-2025`

В форме ввода пароля доступна кнопка с иконкой глаза (👁️) для показа/скрытия введенного текста.

## 📦 Функционал проекта

1. **Экран авторизации (Login Page)**:
   - Защита сайта паролем.
   - Кнопка «Показать/Скрыть пароль» (иконка глаза).
   - Поддержка сохранения сессии в Cookies и LocalStorage.

2. **Главная страница (Cover Page)**:
   - Презентация каталога из 50 промптов по маркетингу и контенту.
   - Разбор 5-элементной формулы инженерного промптинга.
   - Быстрый переход по 5 категориям.
   - Кнопка быстрого скачивания/экспорта всего пака в `.md`.

3. **Интерактивный каталог (50 промптов)**:
   - 5 категорий по 10 промптов в каждой.
   - Поиск по ключевым словам, номеру (#1–#50), роли и ЦА.
   - Быстрый переход к конкретному номеру промпта.
   - Переключение между карточным и компактным списком.
   - Интерактивная замена переменных `[в квадратных скобках]` прямо в карточке.
   - Раскрывающаяся декомпозиция формулы (Роль, Задача, Контекст, Формат, Ограничения).
   - Избранное (сохраняется локально).
   - Копирование готового промпта в один клик.

4. **AI-Генератор кастомных промптов (Gemini API)**:
   - Генерация уникального маркетингового промпта по формуле под ваш индивидуальный продукт и задачу.

5. **Модуль экспорта**:
   - Скачивание всех 50 промптов в формате Markdown одним файлом (`.md`) или быстрое копирование в буфер обмена.
